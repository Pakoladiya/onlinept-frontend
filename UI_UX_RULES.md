# 🎨 UI / UX Rules — Apple Style Web App

## 🎯 Goal

Create a clean, premium, Apple iOS–inspired experience.

---

# 🧠 Core Principles

* Minimal design
* Maximum clarity
* No clutter
* Smooth interactions
* Focus on usability

---

# 🎨 Color System

## Rules:

* Use **1 primary color only**
* Avoid too many colors
* Background must be light

## Example:

* Primary: #39A900
* Secondary: #F6A000
* Background: #FFFFFF
* Text Primary: #111111
* Text Secondary: #666666
* Border: #E5E5E5

---

# 🔤 Typography

## Font:

* Primary: Inter
* Fallback: system-ui

## Sizes:

* Heading: 24–32px
* Subheading: 18–20px
* Body: 14–16px

## Rules:

* No fancy fonts
* Keep readability high
* Use consistent spacing

---

# 📐 Spacing System

Use 8px grid system:

* 8px → small gap
* 16px → normal gap
* 24px → section gap
* 32px → large spacing

---

# 🔲 Components Design Rules

## Buttons

* Height: 44px
* Border radius: 12px
* No heavy shadows
* Smooth hover effect

### Primary Button:

* Solid color (primary)
* White text

### Secondary Button:

* Outline style
* Light border

---

## Cards

* Background: white
* Border radius: 16px
* Shadow: very soft
* Padding: 16–24px

---

## Inputs

* Height: 44px
* Border: 1px solid #E5E5E5
* Focus: highlight with primary color
* Rounded corners: 10–12px

---

# 🧭 Layout Rules

* Max width: 1200px
* Center content
* Use lots of whitespace
* Avoid full-width clutter

---

# ✨ Animations

* Duration: 200–300ms
* Use ease-in-out
* No flashy animations
* Keep it subtle

---

# 📱 Mobile First

* Design for mobile first
* Then scale to desktop
* Buttons must be thumb-friendly

---

# 🚫 What to Avoid

* Too many colors
* Heavy shadows
* Crowded UI
* Small text
* Complex layouts

---

# 💡 UX Rules

* Reduce steps in booking
* Show progress clearly
* Always confirm user actions
* Keep forms short
* Provide feedback (loading, success)

---

# 🏷️ White Label Rules

* All colors come from config
* No hardcoded branding
* Logo always visible on top

---

# 📌 Golden Rule

👉 If it looks simple, clean, and calm — it's correct
👉 If it feels busy — remove something
